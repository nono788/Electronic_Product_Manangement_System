# Electronic_Product_Manangement_System
Electronic Product Management System (EPMS) 

An efficient, client-side web application designed to manage electronic product data seamlessly. This project was built to practice core JavaScript concepts, data persistence, and interactive user interface development. 

Key Features & Functionality 

This system implements full data management capabilities, including: 

* Create: Add new electronic products with detailed attributes.
* Read: Display products dynamically in a structured dashboard.
* Update: Modify existing product details on the fly.
* Delete: Remove individual items or clear the entire product log.
* Search: Filter and locate specific products instantly by name or category.

What I Learned 

Building this project helped me strengthen my foundational front-end development skills: 

* CRUD Operations: Gained a solid understanding of how to manipulate data streams through creating, reading, updating, and deleting objects.
* State Management (Arrays & Local Storage): Learned how to store product objects in runtime arrays and persist that data across browser sessions using localStorage.
* Data Type Conversion: Practiced parsing and casting data types, specifically switching between strings and numbers (using explicit type conversions) to ensure accurate calculations and data integrity.
* Functional Programming: Structured the application using reusable, clean JavaScript functions to keep the codebase organized and maintainable.
* JavaScript Events: Mastered DOM event listeners to handle user interactions like button clicks, real-time typing for search inputs, and page loads.
